<h3 align="center">What I work on</h3>

<p align="center">
I build card-payment systems end to end &mdash; EMV transaction flows on physical terminals and on
softPOS, offline / deferred authorisation, acquirer integrations, and the fleet tooling that keeps
terminals configured, keyed and up to date. A lot of that work is network certification: taking an
integration through L3 against the card schemes, and debugging failures down to individual EMV tags
and ISO fields.
</p>
